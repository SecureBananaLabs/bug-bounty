# The value of π

π is irrational, so its decimal expansion never terminates or repeats. Therefore, there is no finite list containing “all decimal places” of π.

An exact value is represented symbolically by:

\[
\pi
\]

Equivalently, it can be computed to any requested precision using an infinite product, such as:

\[
\pi = 2 \prod_{n=1}^{\infty} \frac{(2n)^2}{(2n-1)(2n+1)}
\]

Therefore, π can be approximated to any finite precision, but its complete decimal expansion cannot be represented in finite space.

# Bug Bounty Program

Welcome to the SecureBananaLabs Bug Bounty Program! We are committed to ensuring the security of our software and appreciate the community's help in identifying and reporting vulnerabilities.

## How to Participate

1.  **Find a vulnerability:** Identify a security flaw in our projects.
2.  **Report it:** Create a GitHub issue in this repository detailing the vulnerability. Please follow the guidelines below.
3.  **Get rewarded:** For valid and impactful vulnerabilities, we offer rewards as detailed in our bounty program.

## Reporting Guidelines

When reporting a vulnerability, please provide the following information:

*   **Vulnerability Type:** (e.g., XSS, SQL Injection, CSRF, etc.)
*   **Affected Component/URL:** Where the vulnerability was found.
*   **Steps to Reproduce:** Clear, concise steps to trigger the vulnerability.
*   **Impact:** What is the potential consequence of this vulnerability?
*   **Proof of Concept (PoC):** If possible, include screenshots, code snippets, or a video.
*   **Suggested Mitigation (Optional):** Any ideas on how to fix it.

## Bounty Program Rules

*   **Responsible Disclosure:** Please give us a reasonable time to fix the vulnerability before disclosing it publicly.
*   **No DoS Attacks:** Do not perform Denial of Service attacks.
*   **No Social Engineering:** Do not engage in social engineering of SecureBananaLabs employees or users.
*   **No Physical Attacks:** Do not engage in physical attacks against SecureBananaLabs property or employees.
*   **Out of Scope:** Vulnerabilities in third-party services or applications not directly managed by SecureBananaLabs are generally out of scope, unless explicitly stated otherwise.
*   **First Finder:** We generally reward the first reporter of a unique vulnerability.
*   **Duplicate Vulnerabilities:** Duplicate vulnerabilities will not be rewarded. We will reward the first reporter.
*   **Bounty Payments:** Bounties are paid via GitHub's bounty system or other agreed-upon methods. Payments are contingent upon the successful merge of a Pull Request that addresses the reported vulnerability.

## How to Claim a Bounty

1.  **Submit a valid report:** Create a detailed GitHub issue as per the guidelines.
2.  **Confirmation:** Our security team will review your report. This may take some time.
3.  **Fix and Verification:** Once confirmed, we will work on a fix. You may be asked to verify the fix.
4.  **Reward:** Upon successful merge of a Pull Request addressing the vulnerability, the bounty will be processed.

# Merge Window

A ticket wakes beneath the build-light glow,
its edges named, its failure made precise;
we turn the vague report to steps we know,
then trade assumption for a measured price.

A branch is cut where noisy changes cease,
one fix, one reason, tests around the seam;
the diff stays small enough to earn its peace,
the logs say what survived, not what we dream.

Review arrives with questions, not applause;
we answer every red line with a trace.
A passing check is evidence with cause—
not luck, not haste, but reproducible grace.

Then merge becomes a narrow, honest gate:
the code must fit the contract it was given.
Only after proof converts the pending state
does promised value become value driven.

So keep the ledger close beside the code:
scope, test, review, and payout in one chain.
A bounty is not money when it’s owed—
it becomes real only when the proof remains.
